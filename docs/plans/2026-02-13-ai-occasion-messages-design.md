# AI-Powered Occasion Messages Design

> Replace static template-based occasion messages with intelligent, personalized messages generated by DeepSeek.

## Problem

Occasion messages (Ramadan, Eid, etc.) use 4 hardcoded templates with simple `{name}` substitution. Every user sees the same patterns. Messages feel generic and robotic.

## Solution

Single batch DeepSeek call that generates unique, personalized messages for all relatives at once, using full relative context (personality, interests, relationship type, communication style).

## Architecture

### Data Flow

```
Screen opens → Check MAX subscription
  → NOT MAX: blurred cards + upgrade CTA
  → IS MAX:
      1. Fetch all relatives with full metadata
      2. Build single batch prompt with all relatives
      3. Call DeepSeek via existing deepseek-proxy edge function
      4. Parse JSON response: { "messages": { "<relative_id>": "<message>", ... } }
      5. Display with staggered fade-in animation
```

### Files Modified

| File | Change |
|------|--------|
| `DeepSeekAIService` | Add `generateOccasionMessages()` method |
| `AIPrompts` | Add `occasionBatchPrompt()` for bulk generation |
| `OccasionMessageService` | Replace template logic with DeepSeek call |
| `OccasionMessagesScreen` | Add loading state, MAX gate, error handling |

### No New Files

Reuse existing infrastructure: `DeepSeekAIService`, `AIPrompts`, `AIEngagingLoader`, `PaywallScreen`.

## Prompt Design

Single batch prompt with all relatives. Key characteristics:

- Relative IDs as JSON keys (not names) for reliable parsing
- Full context per relative: name, relationship type, personality, interests, communication style
- Explicit instruction: make each message unique across the batch
- Target: **20-40 words** per message (short, WhatsApp-ready)
- Reuse existing admin-configurable personality and occasion config
- Response format: `{ "messages": { "id": "msg", ... } }`

## Premium Gating

- Gate behind MAX subscription (add `occasionMessages` to `FeatureIds`)
- Non-MAX users see blurred/locked message cards with upgrade CTA
- Reuse existing `PaywallScreen` navigation pattern

## Loading UX

Reuse `AIEngagingLoader` from message composer with occasion-themed messages:
- Emoji: 🌙
- Rotating messages: "يكتب رسائل رمضان مميزة...", "يختار كلمات دافئة لعائلتك...", "يراعي شخصية كل فرد...", "لحظات وتكون الرسائل جاهزة..."
- Results: staggered fade-in + slide-up per card

## Error Handling

- DeepSeek failure → retry button with Arabic error message (from `AIErrorMessages`)
- Malformed JSON → fall back to old templates for that session
- Missing relative in response → fill with template for just that relative

## Caching

- In-memory only (provider state)
- Navigating away and back = no re-trigger
- Reopening app or next day = fresh generation
