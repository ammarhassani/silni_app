# Silni Terminology Standards

## Notification-adjacent terms

Three Arabic terms with scoped roles. Each term is used ONLY for its surface.
Mixing terms across surfaces creates user confusion.

### `تذكير` — substantive reminder content
The content of a prompt for the user to do something. The reminder itself.
Examples:
- "تذكير يومي" (daily reminder)
- "حان وقت التواصل مع والدتك" (reminder body)
- "تذكيرات اليوم" (today's reminders section)

Surfaces: reminders screen, today's reminders home section, reminder push titles.

### `إشعار` — OS-level delivery channel
The push notification mechanism and the user's preferences for receiving them.
Examples:
- "السماح بالإشعارات" (allow notifications)
- "إدارة الإشعارات" (manage notifications)
- "إعدادات الإشعارات في النظام" (OS notification settings)

Surfaces: settings notification tile, OS-permission dialogs, the cut-but-preserved notification preferences screen.

### `تنبيه` — urgent in-app banner
Important information the user is being interrupted with right now.
Examples:
- "تنبيه: ينتهي اشتراكك خلال ٣ أيام"
- "تنبيه من الإدارة: ..."

Surfaces: announcement banners, in-app message banners, urgent error banners.
