# Silni Brand Standards

## Brand name
The canonical form of the brand name is **`صِلْني`** — fully vowelized.

This form is used everywhere the brand name appears in user-facing surfaces:
text labels, dialogs, notifications, marketing copy, App Store metadata.

It is NOT used in:
- Code identifiers (variable names, class names)
- Package names (`com.silni.app`)
- URLs (`silniapp.com/join/...`)
- Filesystem paths

## AI persona
The AI persona is named **`أنيس`** (companion in solitude). This name appears
in chat greetings, system prompts, suggested-prompt headers, and any UI
surface where the AI introduces itself or is referenced by name.

The word `واصل` is the gamification streak/badge concept and is NEVER used
to refer to the AI persona.
